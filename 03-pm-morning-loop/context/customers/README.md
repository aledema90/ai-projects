# Customer material

Optional. Put files here that tell the loop about your customers: interview transcripts, support
digests, call notes, account summaries. One file per customer or topic, plain Markdown.

Everything here except this file is git-ignored.

Step 3 reads this folder as **context**, not as training: meeting prep (`prep.md`) and new ticket
drafts (`tickets.md`) may quote it, and must cite the file name. If a customer has no file, the output
says "no customer material" instead of guessing.

Tip: name files `<customer>.md` and start each with 3 lines: who they are, what they use, what they
asked for most recently. Meeting notes already in your notes vault (`meetings_folder`) are read too.
